# 离线文字转语音工具 v1.0.0 发布说明

**发布日期**: 2026年1月29日

**版本**: v1.0.0 (首个稳定版本)

## 🎉 版本亮点

离线文字转语音工具v1.0.0是一个功能完整、生产就绪的文字转语音（TTS）解决方案。本版本提供了高质量的中文语音合成、灵活的参数调节、完善的任务队列管理以及友好的用户界面。

### 核心特性

✅ **完全离线运行** - 无需互联网连接，数据安全可靠
✅ **多种音色选择** - 5种精选中文音色，满足不同场景需求
✅ **灵活参数调节** - 语速、音调、音量全方位自定义
✅ **智能队列管理** - 自动排队处理，支持多任务并发
✅ **历史记录管理** - 自动保存生成历史，随时重新下载

## ✨ 新功能

### 1. 文字转语音核心功能

#### 支持的文本类型
- ✅ 纯中文文本
- ✅ 中英文混合文本
- ✅ 带标点符号的自然文本
- ✅ 文本长度：1-5000字符

#### 输出格式
- 📁 **格式**: MP3
- 🎵 **比特率**: 128kbps
- 🔊 **采样率**: 44.1kHz
- 📦 **兼容性**: 所有主流播放器

### 2. 多种音色

提供5种精选中文音色，满足各种场景需求：

| 音色名称 | 特点 | 适用场景 |
|---------|------|---------|
| 晓晓-女声 | 温柔女声（默认） | 有声书、日常朗读 |
| 云扬-男声 | 成熟男声 | 新闻播报、商务场景 |
| 晓悠-童声 | 活泼童声 | 儿童故事、动画配音 |
| 晓伊-年轻女声 | 青春女声 | 年轻化内容、短视频 |
| 云健-沉稳男声 | 沉稳男声 | 纪录片、教育内容 |

### 3. 语音参数自定义

#### 语速调节
- **范围**: 0.5x - 2.0x
- **默认**: 1.0x（正常速度）
- **推荐值**:
  - 0.8x: 慢速讲解
  - 1.0x: 正常朗读
  - 1.2x: 快速播报

#### 音调调节
- **范围**: 0.5x - 2.0x
- **默认**: 1.0x（自然音调）
- **推荐值**:
  - 0.9x: 低沉音调
  - 1.1x: 高亢音调

#### 音量调节
- **范围**: 0% - 100%
- **默认**: 100%（最大音量）

### 4. 任务队列管理

- **队列容量**: 最多10个任务
- **处理模式**: FIFO（先进先出）
- **实时状态**: 显示排队/处理/完成数量
- **任务取消**: 支持取消排队中的任务
- **自动处理**: 后台自动顺序处理

### 5. 历史记录功能

- **自动保存**: 每个完成的任务自动记录
- **保留数量**: 最多20条（FIFO自动清理）
- **记录内容**: 文本摘要、参数、时间、文件路径
- **支持操作**:
  - 查看历史列表
  - 重新下载音频
  - 删除单条记录
  - 清空所有记录

## ⚠️ 已知问题

### 限制和约束

1. **首次使用较慢**
   - **现象**: 首次使用某个音色需要下载模型文件（50-100MB）
   - **影响**: 首次生成时间较长（1-3分钟）
   - **解决**: 耐心等待，模型会缓存到本地

2. **队列限制**
   - **现象**: 队列最多支持10个任务
   - **影响**: 超过10个任务会报错
   - **解决**: 等待队列处理完毕或取消不需要的任务

3. **历史记录限制**
   - **现象**: 最多保留20条历史记录
   - **影响**: 超过20条会自动删除最早的记录
   - **解决**: 及时下载重要的音频文件

4. **文本长度限制**
   - **现象**: 单次转换文本最长5000字符
   - **影响**: 超长文本无法一次转换
   - **解决**: 将文本分段处理

5. **繁体中文支持有限**
   - **现象**: 繁体中文发音效果不如简体
   - **影响**: 繁体中文音频可能不够自然
   - **解决**: 建议转换为简体中文使用
