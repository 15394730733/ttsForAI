## 简介

离线文字转语音工具是一款基于edge-tts引擎的文字转语音（TTS）工具，可以将文本转换为高质量的MP3音频文件。

### 主要特点

- ✅ **完全离线** - 无需互联网连接，本地运行
- ✅ **多种音色** - 支持5种高质量中文音色
- ✅ **参数自定义** - 可调节语速、音调、音量
- ✅ **批量处理** - 支持任务队列管理
- ✅ **历史记录** - 自动保存生成历史
- ✅ **简单易用** - 友好的Web界面

### 适用场景

- 📚 有声书制作
- 🎙️ 配音制作
- 📢 广告配音
- 📖 文章朗读
- 🎵 音频内容创作

## 快速开始

### 第一步：启动服务

#### Windows用户

1. 双击运行 `backend/start_server.bat`
2. 等待服务启动（看到"Uvicorn running"提示）
3. 双击运行 `frontend/npm run dev.bat` 或在命令行执行：
   ```bash
   cd frontend
   npm run dev
   ```

#### macOS/Linux用户

1. 启动后端服务：
   ```bash
   cd backend
   source venv/bin/activate
   python -m uvicorn src.main:app --reload
   ```

2. 启动前端服务（新终端）：
   ```bash
   cd frontend
   npm run dev
   ```

### 第二步：打开浏览器

在浏览器中访问: **http://localhost:5173**

### 第三步：开始使用

1. 在文本框中输入要转换的文字
2. 选择音色和参数（可选）
3. 点击"生成语音"按钮
4. 等待生成完成后下载音频文件

## 功能介绍

### 1. 文字转语音

将任意中文或中英文混合文本转换为语音音频文件。

- 支持最长5000字符的文本
- 自动过滤特殊字符和控制字符
- 保留换行符和基本标点

### 2. 音色选择

提供5种预设音色：

| 音色名称 | 特点 | 适用场景 |
|---------|------|---------|
| 晓晓-女声 | 温柔女声（默认） | 日常朗读、有声书 |
| 云扬-男声 | 成熟男声 | 新闻播报、商务场景 |
| 晓悠-童声 | 活泼童声 | 儿童故事、动画配音 |
| 晓伊-年轻女声 | 青春女声 | 年轻化内容、短视频 |
| 云健-沉稳男声 | 沉稳男声 | 纪录片、教育内容 |

### 3. 语音参数调节

#### 语速（Rate）
- **范围**: 0.5x - 2.0x
- **默认**: 1.0x（正常速度）
- **建议**:
  - 0.8x: 慢速讲解
  - 1.0x: 正常朗读
  - 1.2x: 快速播报
  - 1.5x: 极速浏览

#### 音调（Pitch）
- **范围**: 0.5x - 2.0x
- **默认**: 1.0x（正常音调）
- **建议**:
  - 0.8x: 低沉音调
  - 1.0x: 自然音调
  - 1.2x: 高亢音调

#### 音量（Volume）
- **范围**: 0% - 100%
- **默认**: 100%（最大音量）
- **建议**: 根据实际听感调整

### 4. 任务队列管理

- 支持最多10个任务排队
- 实时显示队列状态
- 可取消排队中的任务
- 自动按顺序处理任务

### 5. 历史记录

- 自动保存最近20条生成记录
- 显示文本摘要、参数、时间
- 支持重新下载历史音频
- 支持删除单条或全部记录

## 使用指南

### 基础使用流程

#### 1. 输入文本

在文本输入框中输入或粘贴要转换的文字：
- 支持直接输入
- 支持从其他文档复制粘贴
- 自动显示字符计数（0/5000）

**提示**:
- 文本不能为空
- 超过5000字符会被截断
- 特殊字符会被自动过滤

#### 2. 选择音色

在"音色选择"下拉菜单中选择合适的音色：
- 默认音色：晓晓-女声
- 点击下拉菜单查看所有可用音色
- 鼠标悬停查看音色说明

#### 3. 调整参数（可选）

根据需要调整语音参数：

**语速调节**:
```
慢速 ←━━━○━━━→ 快速
0.5x  1.0x  2.0x
```

**音调调节**:
```
低沉 ←━━━○━━━→ 高亢
0.5x  1.0x  2.0x
```

**音量调节**:
```
静音 ←━━━○━━━→ 最大
0%   50%   100%
```

#### 4. 生成语音

点击"生成语音"按钮开始生成：
- 按钮会显示加载动画
- 可以在"队列状态"中查看进度
- 生成完成后会自动显示下载按钮

#### 5. 下载音频

生成完成后：
- 点击"下载音频"按钮
- 音频文件会保存到浏览器下载目录
- 文件名格式：`tts_[任务ID].mp3`

### 高级使用技巧

#### 1. 批量生成

如果想生成多段文本：

1. 生成第一段文本
2. 不要关闭页面
3. 修改文本内容
4. 继续生成下一段
5. 所有任务会自动排队处理

**注意**: 队列最多支持10个任务

#### 2. 参数预设

找到理想的参数组合后：
- 记下参数值（如：语速1.2、音调1.0、音量0.9）
- 下次使用时直接设置相同参数
- 点击"重置参数"可恢复默认值

#### 3. 音色对比

想对比不同音色效果：
1. 使用相同文本
2. 仅更改音色
3. 分别生成并下载
4. 播放对比效果

#### 4. 长文本处理

对于超过5000字符的长文本：
1. 将文本分段（每段<5000字符）
2. 逐段生成音频
3. 使用音频编辑软件合并

## 常见问题

### Q1: 生成速度慢怎么办？

**A**:
- 首次使用某个音色需要下载模型（50-100MB），请耐心等待
- 文本越长，生成时间越长（约50-100字符/秒）
- 关闭其他占用CPU的程序
- 确保网络连接正常（首次下载音色模型需要）

### Q2: 音质不理想怎么办？

**A**:
- 尝试调整语速（建议0.8-1.2之间）
- 尝试不同音色
- 调整音调参数
- 检查文本是否有特殊字符
- 使用简体中文（繁体中文支持有限）

### Q3: 生成失败怎么办？

**A**:
- 检查文本是否超长（最多5000字符）
- 检查文本是否包含非法字符
- 查看错误消息提示
- 刷新页面重试
- 检查后端服务是否正常运行

### Q4: 队列满了怎么办？

**A**:
- 等待队列中的任务完成
- 或取消不需要的任务
- 队列最多支持10个任务

### Q5: 下载的音频文件在哪？

**A**:
- 默认保存在浏览器下载目录
- 文件名格式：`tts_[任务ID].mp3`
- 可以在浏览器下载历史中查找

### Q6: 可以在手机上使用吗？

**A**:
- 如果服务部署在局域网内，可以通过手机浏览器访问
- 需要手机和电脑在同一网络
- 访问地址：`http://[电脑IP]:5173`

### Q7: 支持英文吗？

**A**:
- 支持中英文混合文本
- 英文发音可能不够自然（主要针对中文优化）
- 纯英文建议使用专门的英文TTS工具

### Q8: 能添加背景音乐吗？

**A**:
- 当前版本不支持
- 可以生成音频后使用音频编辑软件添加背景音乐
- 后续版本可能会考虑此功能

### Q9: 音频文件格式是什么？

**A**:
- 输出格式：MP3
- 比特率：128kbps
- 采样率：44.1kHz
- 兼容性：支持所有主流播放器

### Q10: 历史记录会一直保存吗？

**A**:
- 系统自动保留最近20条记录
- 超过20条会自动删除最早的记录
- 建议及时下载重要音频

## 故障排查

### 问题1: 后端服务无法启动

**症状**: 双击bat文件后窗口闪退或报错

**解决方法**:
1. 检查Python是否已安装（需要Python 3.10+）
   ```bash
   python --version
   ```
2. 检查虚拟环境是否已创建
   ```bash
   cd backend
   dir venv
   ```
3. 手动激活虚拟环境并安装依赖
   ```bash
   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. 检查端口8000是否被占用
   ```bash
   netstat -ano | findstr :8000
   ```

### 问题2: 前端页面无法打开

**症状**: 浏览器显示"无法访问此网站"

**解决方法**:
1. 检查前端服务是否启动
   ```bash
   cd frontend
   npm run dev
   ```
2. 检查Node.js是否已安装
   ```bash
   node --version
   npm --version
   ```
3. 检查依赖是否安装
   ```bash
   cd frontend
   npm install
   ```
4. 检查端口5173是否被占用

### 问题3: 生成任务一直排队

**症状**: 任务状态一直显示"排队中"

**解决方法**:
1. 检查后端队列处理器是否正常运行
2. 查看后端日志
   ```bash
   tail -f backend/logs/tts_app.log
   ```
3. 重启后端服务
4. 检查是否有任务卡住

### 问题4: 音频文件无法播放

**症状**: 下载的MP3文件无法播放

**解决方法**:
1. 检查文件大小（是否为0KB）
2. 尝试使用其他播放器
3. 检查任务是否真的完成（状态应为"completed"）
4. 重新生成任务

### 问题5: 页面显示错误

**症状**: 浏览器控制台有错误信息

**解决方法**:
1. 按F12打开浏览器开发者工具
2. 查看Console标签的错误信息
3. 查看Network标签的请求状态
4. 清除浏览器缓存（Ctrl+Shift+Delete）
5. 尝试使用其他浏览器

### 问题6: 首次使用音色很慢

**症状**: 第一次使用某个音色时特别慢

**解决方法**:
- 这是正常现象，需要下载音色模型
- 模型大小约50-100MB
- 下载完成后会缓存到本地
- 下次使用会快很多
