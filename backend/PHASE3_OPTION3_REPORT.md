## ✅ 完成的工作

### 1. 问题修复

#### 问题1: 后台任务数据库会话失效
**症状**: 任务创建后一直停留在 `queued` 状态

**根本原因**: FastAPI 的 `BackgroundTasks` 中复用请求的数据库会话，当后台任务执行时，原始请求的会话可能已经关闭。

**解决方案**: 修改 `process_task` 函数，让其创建自己的数据库会话：

```python
async def process_task(task_id: str) -> None:
    """Background task to process TTS generation."""
    from src.core.database import async_session_maker

    async with async_session_maker() as db:
        # 处理逻辑...
```

**修改文件**: `backend/src/api/tts.py`
